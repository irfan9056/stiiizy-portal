# STIIIZY Maintenance Portal

Work-order portal for STIIIZY's stores and production sites, run by Prime Property Maintainers LLC.

- **Live demo:** https://irfan9056.github.io/stiiizy-portal/ (tickets save in your browser; nine example tickets preloaded)
- File a ticket, price it, approve the budget, route to a direct vendor or DMG, schedule, complete with photos, sign off, invoice, close.
- Roles: store or site, STIIIZY approver, Prime PM assessor (switch at the top right).
- Reports: approved budget vs vendor spend vs Prime PM fee, by region, trade, route; CSV export.

`docs/index.html` is the published page. `portal_template.html` builds it (the location list is embedded at build time).
